# C Notes — From Fundamentals to Systems Programming

A structured, practical and deep-learning repository for mastering the C programming language — from basic syntax to pointers, memory management, data structures, concurrency and systems programming.

> **Learn → Code → Break → Debug → Understand → Build**

---

## 🎯 Goal

This repository is not intended to be a collection of syntax notes.

The goal is to understand **how C actually works underneath the code**.

Topics progress from:

```text
C Fundamentals
      ↓
Functions & Data Structures
      ↓
Pointers
      ↓
Dynamic Memory
      ↓
Compilation & Linking
      ↓
Memory & CPU Concepts
      ↓
Concurrency
      ↓
Networking
      ↓
System Programming
      ↓
Real-World Projects
```

## 🔬 What Makes These Notes Different?

The repository focuses on questions such as:

* What happens in memory?
* What does the compiler actually generate?
* Why does this code produce undefined behavior?
* How does pointer arithmetic work?
* What happens during `malloc()`?
* Why does structure padding exist?
* How does a function call use the stack?
* What happens during linking?
* How do processes and threads differ?
* How does a socket communicate with another machine?
* How can C programs fail because of memory corruption?
